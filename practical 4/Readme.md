# Practical 4: Decimal to Binary Conversion Using Stack

## Practical Title
Decimal to Binary Conversion Using Stack.

## Problem Statement
Convert a decimal integer to its binary equivalent using a stack to reverse the order of the remainders generated by repeated division by two.

## Objective
- Understand the stack data structure and its LIFO principle.
- Use push-like insertion and pop-like retrieval to reverse a sequence.
- Apply repeated division to convert decimal numbers to binary.

## Algorithm / Approach
1. Read a decimal integer `n`.
2. Initialise an array stack and set `top = -1`.
3. While `n != 0`, calculate `remainder = n % 2`, update `n = n / 2`, and push the remainder onto the stack.
4. Pop/print the stored remainders from `top` down to zero.
5. If the input is zero, handle it as binary `0` (the supplied code does not currently handle this case).

## Data Structure / Concept Used
- Array-based stack
- LIFO (Last In, First Out)
- Modulo and integer division

## Test Cases
| Test case | Decimal input | Expected binary output |
|---|---:|---|
| Zero | 0 | `0` (requires explicit zero handling) |
| Small value | 5 | `101` |
| Power of two | 8 | `1000` |
| Larger value | 25 | `11001` |

## Sample Input and Output
```text
Enter Decimal number: 25
Binary number for given decimal number is: 11001
```

## Time Complexity
**O(log n)** for a positive decimal input `n`, because each division by two halves the number.

## Space Complexity
**O(log n)** stack space for the generated binary digits. The supplied implementation uses a fixed array of 10 elements, so it is limited for larger inputs.

## Conclusion
The stack restores the correct order of binary digits because the last remainder generated is the first one printed. This practical demonstrates LIFO behaviour in number-system conversion.
